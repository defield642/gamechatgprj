# Multiplayer Tic-Tac-Toe

A real-time multiplayer Tic-Tac-Toe game with private room codes. Two players on separate devices can join the same room and play.

## Features
- Create a room and get a 4-character code
- Join a room with a code
- Real-time turns and board updates
- Win/draw detection
- Rematch
- Mobile-friendly UI
- Clear rules displayed in the lobby
